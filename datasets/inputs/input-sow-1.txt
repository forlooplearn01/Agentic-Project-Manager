Description of Services
U. S. Tire & Exhaust (USTE) has requested assistance in the installation and configuration of
WebSphere Application Server 6.1 onto two Red Hat Linux Enterprise 5.0 servers. These
applications will be used by USTE to interface with a solution provided by Neumonics.
Berbee will install and configure RHLE and WebSphere Application Server 6.1 on these servers.
Berbee will ensure working instances of WebSphere Application server via the use of IBM’s
Sample Applications.
After these application servers have been installed, Berbee will work with the USTE and
Neumonics team to tune the environment for best performance.
The high level tasks to be performed by Berbee include:
1. Install Redhat Linux 5.0 on each server.
2. Install WAS 6.1 on each Redhat Linux server.
3. Apply fixpack(s) to WAS 6.1 on each Redhat Linux server.
4. Install Apache or IBM HTTP Server on each Redhat Linux server.
5. Apply fixpack(s) to IBM HTTP Server, if installed, on each Redhat Linux server.
6. Configure plug-in in HTTP servers to forward requests to WAS servers.
7. Assist with tuning of Websphere Application Server software.
