PROJECT SCOPE
Seller will assist Customer with discovery, design, advisory and implementation services towards the following Customer
objectives.

ARIA OPERATIONS
Environment sizing and deployment.
Deploy and configure relevant TVS modules for our environment.
Setup Integrations with NSX-T and other Aria products.
Create two multi-tiered application monitoring dashboards.
Configure Cost Reporting.
Create process to address VMs with low disk space.

ARIA AUTOMATION
Environment sizing and deployment.
IPAM integration with Infoblox BloxOne DDI.
Build Windows server VM deployment blueprint.
Build Windows server VM decommission blueprint.
Create Service Catalog.
Implement Freshservice ITSM Integration.

BROWNFIELD VCF FOR WORKLOAD VCENTER/NSX/CLUSTERS
Confirm if we can migrate our non-VCF managed hosts and NSX environment into VCF.
Remediation steps to prepare for migration.
Complete VCF Brownfield migration.
